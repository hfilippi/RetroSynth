# 1. Introduction

This document establishes the official charter of the RetroSynth Project.

It defines the project's purpose, scope, engineering principles, governance model, and long-term vision.

All technical and organizational decisions shall remain aligned with the principles defined in this charter.

---

# 2. Project Overview

RetroSynth Project is an open-source initiative dedicated to preserving, studying and extending the sound technologies of classic computers, video game consoles and vintage sound chips through modern hardware and software engineering.

The project aims to provide a modular ecosystem composed of hardware, firmware, desktop software, development tools and comprehensive technical documentation.

RetroSynth is designed as an engineering platform rather than a single product.

---

# 3. Vision

To become a reference open platform for retro digital sound synthesis, enabling musicians, developers and enthusiasts to explore, preserve and create using the technologies that shaped the history of digital audio.

---

# 4. Mission

RetroSynth Project develops open hardware, open software and open documentation that make classic sound technologies accessible through modern engineering practices.

The project seeks to preserve historical knowledge while encouraging innovation and creative experimentation.

---

# 5. Core Values

The RetroSynth Project is built upon the following values:

- Engineering excellence
- Openness
- Long-term maintainability
- Transparency
- Community collaboration
- Historical preservation
- Technical accuracy
- Continuous improvement

---

# 6. Project Scope

RetroSynth Project includes:

- Hardware design
- Embedded firmware
- Desktop applications
- Software Development Kit (SDK)
- Technical documentation
- Development tools
- Website and documentation portal
- Community resources

---

# 7. Non-Goals

The project does not aim to:

- Replicate proprietary commercial products.
- Circumvent copyright or licensing restrictions.
- Distribute copyrighted firmware or ROM images without authorization.
- Sacrifice maintainability for rapid feature growth.
- Lock users into proprietary ecosystems.

---

# 8. Engineering Principles

All engineering decisions shall follow these principles:

1. Architecture before implementation.
2. Documentation is part of the product.
3. Open standards whenever possible.
4. Modularity over complexity.
5. Quality over quantity.
6. Performance with maintainability.
7. Backward compatibility when practical.
8. Automation whenever appropriate.
9. Reproducible builds.
10. Continuous documentation.

---

# 9. Governance

RetroSynth Project is maintained through an open and transparent development process.

Technical decisions are documented through Architecture Decision Records (ADR).

All contributions shall follow the project's documented engineering standards.

---

# 10. Decision Making

Major technical decisions shall:

- be documented;
- be technically justified;
- be reviewable;
- preserve the long-term goals of the project.

Whenever appropriate, significant architectural decisions shall be recorded as ADRs.

---

# 11. Licensing

RetroSynth Project adopts an open-source licensing strategy.

Software components are released under the GNU General Public License v3.0 unless otherwise specified.

Documentation and hardware licensing are defined in their respective project policies.

---

# 12. Success Criteria

The success of the RetroSynth Project will be measured by:

- Technical quality
- Documentation quality
- Community participation
- Long-term maintainability
- Educational value
- Hardware reproducibility
- Software reliability

Commercial success is not a project objective.

---

# 13. Guiding Principle

> Build systems that will still be understandable, maintainable and enjoyable to use ten years from now.
